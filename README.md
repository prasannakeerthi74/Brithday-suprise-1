# 🎂 Birthday Surprise Website

A beautiful and interactive birthday surprise website created using
HTML, CSS, and JavaScript.

## ✨ Features

- 🎈 Floating balloons animation
- ❤️ Floating hearts animation
- ✨ Animated birthday title
- 💌 Interactive letter opening
- 🎁 Animated surprise gift box
- 🎉 Confetti celebration
- 💖 Personalized birthday message
- 📱 Mobile responsive design
- 🌸 Cute and attractive birthday theme

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this project.
2. Open the project folder in VS Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` in your browser.

## 🎀 How It Works

### Step 1
The website starts with:

"Happy Birthday Navya 🎂"

with floating balloons, hearts and animations.

### Step 2
Click:

"💌 Open Your Surprise"

to open the birthday letter.

### Step 3
Read the personalized birthday message and click:

"🎁 One More Surprise"

### Step 4
Click the gift box to open it.

A final birthday message and confetti animation will appear.
